# Resume Website

This project is a polished one-page static resume website for Sarika Saini.
It highlights education, projects, technical skills, certifications, achievements, and contact details in a clean and responsive layout.

## Features
- Responsive single-page layout
- Professional resume sections
- Clickable contact and profile links
- Easy to view locally or deploy on GitHub Pages

## How to view it
1. Open the project folder in your browser.
2. Open index.html to view the resume website.

## Project files
- index.html — main structure of the resume page
- styles.css — styling and responsive layout
